## Обзор

Телеграм-бот для поиска фильмов и сериалов: пользователь вводит название, бот находит метаданные (год, рейтинг, описание, постер) через API Кинопоиска и подбирает рабочую ссылку на видео через Kodik/HDRezka. Есть постраничная навигация по результатам поиска и список избранного на пользователя.

## Статус: почему бот отключён

После обнаружения взлома (13 июля 2026) бот был немедленно удалён через BotFather. При аудите репозитория обнаружилось, что:

- в истории git был публично виден реальный токен Telegram-бота (несколько версий, начиная с 2024 года);
- там же был публично виден рабочий ключ API Кинопоиска, в том числе захардкоженный прямо в исходном коде старой версии бота.

Токен бота уже бесполезен для атакующего (бот удалён). Ключ Кинопоиска технически ещё можно было перевыпустить, но было решено **не тратить на это время и полностью убрать интеграцию с Кинопоиском из кода**, а сам проект — архивировать. Токен и ключ API нигде в текущем коде и истории git больше не встречаются.

## Основные функции (когда бот работал)

1. **Поиск фильмов и сериалов** — поиск по названию через API Кинопоиска (kinopoisk.dev), с постраничной навигацией по результатам.
2. **Карточка фильма** — год, рейтинги КП/IMDB, описание, постер; ссылка на плеер, если видео удавалось найти через Kodik или HDRezka.
3. **Сериалы** — отдельная клавиатура с сезонами, если источник отдавал такую структуру.
4. **Избранное** — до 30 фильмов/сериалов на пользователя, хранилось в SQLite (aiosqlite).
5. **Rate limiting** — ограничение частоты запросов на пользователя, чтобы не долбить сторонние источники.

## Архитектура

```
bot/
  main.py              — точка входа, регистрация хендлеров
  config.py            — загрузка токена/настроек (env вместо секретов в файлах)
  db/database.py       — избранное на SQLite (aiosqlite)
  handlers/            — обработчики команд/кнопок Telegram
  services/
    kinopoisk.py        — обёртка над kinopoisk.dev (отключена, см. выше)
    searcher.py          — объединяет метаданные + поиск видео
  sources/
    kodik.py             — поиск/встраивание через Kodik CDN (по токену)
    hdrezka.py            — скрейпинг HDRezka как fallback-источник видео
  utils/               — форматирование сообщений, клавиатуры, rate limiter
```

Секреты (`BOT_TOKEN`, `KODIK_TOKEN`) передавались через переменные окружения, а не хранились в репозитории — это внедрено уже после инцидента вместе с очисткой истории git.

## Локальный запуск (историческая инструкция)

Бот не эксплуатируется и не будет отвечать (Telegram-токен отозван), но код рабочий и его можно поднять для ознакомления:

```bash
git clone https://github.com/dantemorrigan/48-91KINO_bot.git
cd 48-91KINO_bot/bot
python -m venv venv && source venv/bin/activate
pip install -r requirements.txt

export BOT_TOKEN="свой_токен"          # обязателен
export KODIK_TOKEN="свой_токен_kodik"  # опционально

python main.py
```

Поиск метаданных через Кинопоиск отключён навсегда (ключ вырезан из кода) — `KinopoiskService` теперь всегда возвращает пустой результат без сетевых запросов.

## Известные ограничения

Бот использовал сторонние источники (Kodik, HDRezka) для получения ссылок на видео — при изменении структуры этих сайтов или API соответствующая часть переставала работать. Это унаследованная архитектурная особенность, а не то, что стоит исправлять — проект в архиве.
